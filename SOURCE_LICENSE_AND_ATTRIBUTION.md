## Source dataset

hypercholesterolemia**

Mendeley Data, Version 1

DOI: `10.17632/6cm8mxm5rm.1`

Original contributors listed by the repository include Helen Griffiths,
Maria Cristina Polidori, Gregory Lip, Irundika Dias, Ivana Milic and
Andrew Devitt.

The Mendeley Data record identifies the dataset license as:

**Creative Commons Attribution-NonCommercial 3.0 (CC BY-NC 3.0).**

The source workbook itself is not redistributed by this repository.

## Adaptation statement

This repository contains computationally derived statistical summaries,
rank transformations, exact-permutation results, multivariate
statistics and publication visualizations generated from the public
source material.

These derived source-dependent artifacts are clearly separated from the
project's original executable software and documentation.

The derived source-dependent artifacts are distributed conservatively
under CC BY-NC 3.0 and retain attribution to the original dataset.
