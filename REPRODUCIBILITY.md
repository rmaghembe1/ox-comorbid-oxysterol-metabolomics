# Reproducibility

The computational project used provenance-first execution with
SHA256-bound inputs and outputs.

Key principles were:

1. Measurement scale was adjudicated before inferential execution.
2. Clinical-block reconstruction was recorded as indirect rather than
   silently treated as direct participant metadata.
3. Primary statistical families were prespecified before execution.
4. Exact finite permutation spaces were used where computationally
   feasible.
5. Network-edge localization was conditional on support for the global
   network statistic.
6. Publication figures were generated from frozen statistical outputs.
7. Final figures underwent manual visual QA before manuscript assembly.
8. New inferential families were not introduced during manuscript
   preparation.

The public package intentionally separates the original public source
dataset from derived computational results.
